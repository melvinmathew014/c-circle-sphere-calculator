# Circle Area and Sphere Calculations in C

A beginner-friendly C program that calculates the area of a circle, the surface area of a sphere, and the volume of a sphere using a radius provided by the user.

## 📌 Features

* Accepts the radius as user input.
* Calculates the area of a circle.
* Calculates the total surface area of a sphere.
* Calculates the volume of a sphere.
* Displays the results with formatted decimal precision.

## 🧮 Mathematical Formulas

The program uses the following formulas:

| Calculation              | Formula                    |
| ------------------------ | -------------------------- |
| Area of a circle         | \(A = \pi r^2\)            |
| Surface area of a sphere | \(S = 4\pi r^2\)           |
| Volume of a sphere       | \(V = \frac{4}{3}\pi r^3\) |

Where:

* \(r\) = Radius
* \(\pi\) ≈ 3.14159265359

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/melvinmathew014/c-circle-sphere-calculator.git
```



### 2. Navigate to the project folder

```bash
cd "C Programing"
```

### 3. Compile the program

If GCC is installed, run:

```bash
gcc circle_calc-o calculations
```

### 4. Execute the program

On Windows:

```bash
.\calculations.exe
```
